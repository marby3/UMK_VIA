# VMK Firmware & KeyBind 開発タスクリスト

## フェーズ1：プロジェクト基盤の構築
基本的にすべてブラウザで完結させるが、PCでのファームウェアビルドは学習用にできる状態にする。完成後はOSS（GitHub）として公開。

- [x] リポジトリの作成とディレクトリ構成の設計（ユーザーが開発に参加しやすい構成に配慮）
- [x] PC（ローカル）でのファームウェアビルド環境の構築（学習・コントリビュート用）
- [x] ドキュメント作成基盤の用意（AIを活用した作成フローを想定）
- [x] 開発ユーザー向けガイド・コントリビュートガイドの作成

## フェーズ2：共通UI/UXの実装（GUIのアイデア）
ヘッダーをベースに、接続前でも各機能のタブが表示されるようにする。

- [ ] トップページ・基本レイアウトの実装（トップのヘッダーにはコピーライトを表示）
- [ ] ヘッダーナビゲーションの実装（ファーム書き込み / キーマッピング / 動作テスター / レイアウト / 開発ユーザー / 設定 / 空白分割 / リンク集）
- [ ] 各種設定を格納するサイト設定画面の構築
- [ ] リンク集の構築（アイコンとURLを登録できる機能）
- [ ] ボディ部分の画面切り替え（ルーティング）の実装

## フェーズ3：【開発ユーザー向け】キーレイアウトの作成支援（GUI）
キーボード定義データを作成・管理する機能。

- [ ] `kle-ng` (MITライセンス) を参考・フォークしたレイアウトエディタの基礎実装
- [ ] 不要な機能（キーの印字調整、メタデータ、サマリー機能など）の削除・非表示化
- [ ] JSON等、適切なファイル形式でのキーボード定義データダウンロード機能
- [ ] 定義データをまとめてアップロード・パースできる機能の検討・実装

## フェーズ4：【開発ユーザー向け】ファームウェアの作成支援（GUI）とビルド
高度なマイコン用ファームとは差別化し、ブラウザ上で直感的にファームウェアを作成・ビルドする機能。

- [ ] タブ移動を極力なくした、1画面完結型UIの設計
- [ ] 基板設計ライクな「ピン配置GUI」の実装（シンボルほど簡略化しないが直感的に結線）
- [ ] 各種機能（Col, Row, 分割, RGB, エンコーダー等）とマイコンピンの結線ロジック実装
- [ ] Col / Row のピン増減機能（ユーザー指定数に応じて Col0, Col1... / Row0, Row1... を生成）
- [ ] RGB LEDに必要なピン（Din, 電源, GND）の追加機能
- [ ] ロータリーエンコーダーに必要なピン（A相, B相, GND）の追加機能
- [ ] その他機能のピン名登録・セット追加機能
- [ ] VendorID / ProductID の入力UI実装（未入力状態のプレースホルダとして `VID:0x1209`, `PID:0xb803` を用意）
- [ ] キー組み合わせ入力（Ctrl, Shift, Alt, Winの4つをチェックボックスで同時押し）の設定UI
- [ ] ブラウザ上でのビルド実行環境の構築（コマンドラインではなくGUI上から実行）
- [ ] ビルド前チェック：CH32マイコンのFlashメモリ容量の余裕確認と、サイズ超過時のエラー通知機能

## フェーズ5：【一般ユーザー向け】書き込み・キーマッピング ＆ サーバー検証
ユーザーがファームを書き込み、キーを割り当てるコア機能。および早期段階でのサーバー動作検証環境の構築。

- [ ] **サーバー検証環境の構築**
  - [ ] GitHub等から連携した自動デプロイ環境（CI/CD）の構築
  - [ ] HTTPS環境でのWebUSB動作確認、ブラウザ・サーバー間の通信・ビルドテスト
- [ ] **ファームウェア書き込み機能 (Web Flasher)**
  - [ ] `WebLink_USB` や `rv003usb-webflasher` (MIT) を参考にしたブラウザ書き込み処理の実装
  - [ ] 書き込み進捗および結果ログの画面表示
  - [ ] 正常書き込み完了後、キーマッピング画面への遷移を促す機能（自動遷移はしない）
- [ ] **キーマッピング (KeyBind)**
  - [ ] マイコン未接続時の待機UI（ローディングアニメーション等。接続前はマッピング画面を非表示）
  - [ ] 定義データのアップロードによる画面上部へのレイアウト表示
  - [ ] キー設定変更機能：画面上部のキーをクリックして変更（ドロップダウン・検索機能で選択）
  - [ ] キー設定変更機能：画面下部からレイアウト上のキーへ、キーコードをドロップダウンして変更
  - [ ] 画面下部の構築：キーコードの分類タブ、検索バーの実装
  - [ ] 画面下部の構築：Basicキー（基本USB HIDキーコード）を104キーボード風の配置で表示
  - [ ] 「キーマップ書き込み」「キーマップ初期化」ボタンの配置（誤操作防止のため間隔を十分に空ける）

## フェーズ6：【一般ユーザー向け】動作テスト機能
設定したレイアウトでどのキーが反応しているか視覚的に確認するテスター。

- [ ] 指定レイアウト上でのキースイッチの動作状態（入力前・入力中・入力後）のUI反映ロジック
- [ ] 定義データがアップロードされている場合の、カスタムレイアウト上での動作確認機能
- [ ] 定義データがない場合のデフォルトレイアウト表示（104英語キーボード / 109日本語キーボード）
