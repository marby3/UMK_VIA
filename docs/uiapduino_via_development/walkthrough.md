# UIAPduino_VIA プロジェクト総括 (Phase 5 完了)

このドキュメントは、プロジェクトの最終成果物とその使い方をまとめたガイドです。

## Phase 5 で構築された Webフロントエンド

プロジェクトルートの `web` ディレクトリ内に、以下のWebフロントエンド一式を作成しました。
フレームワーク（React等）は使わず、すべての環境ですぐに動かせる完全なVanilla HTML/CSS/JS構成で構築されています。

1. **`index.html`**:
   UIAPduinoと接続するためのUI構造。4レイヤー選択、4x6のマトリックスプレビューと設定用モーダルが組み込まれています。
2. **`styles.css`**:
   グラスモーフィズム（半透明にぼかしたガラス調）を取り入れ、ダークモードかつネオングリーン・ブルーを基調としたモダンでおしゃれな「Wow!!」と驚くリッチデザインをVanilla CSSのみで再現しました。
3. **`protocol.js`**:
   WebHID API (`navigator.hid`) の抽象化ラッパーです。`VID: 0x1209` / `PID: 0xC003` (UIAPduino_VIA) を狙い撃ちし、`0x01` (Key write) や `0x99` (Flash save) の8バイトパケットを `Endpoint 0` へ直に発行します。
4. **`hid_app.js`**:
   アプリの心臓部となるロジック。キーがクリックされたときの挙動、QMKキーコードの解釈表示、そしてFlashへの保存時に切断(`disconnect` イベント)が発生した際のUIリセットを司ります。

## ブラウザでの起動・連携テスト方法

1. **ブラウザの準備**:
   Google Chrome または Microsoft Edge が必要です（WebHID API対応ブラウザ）。
2. **HTMLの起動**:
   ローカルファイルの `web/index.html` をダブルクリックしてブラウザで開きます。（ローカルファイルプロトコル `file:///` からでも WebHID 機能は動作することが多いですが、もし弾かれる場合は簡単なローカルサーバー `python -m http.server` 等で開いてください）。
3. **デバイスの接続**:
   マイコンをUSBに繋いだ状態で、「デバイスに接続」ボタンをクリックするとブラウザの権限ポップアップが出ます。リストから `UIAPduino_VIA` を選択して許可してください。
4. **キーの動的変更**:
   表示されているマトリックスキーの「[0,0] (A)」などをクリックし、モーダルにて「Space」や「Shift」などに変えて適用ボタンを押してください。**この瞬間、マイコンのRAMデータが更新**され、該当のピンを先ほどのようにショットさせると変更された新しいキーとして文字が打たれます。
5. **Flashへの永続化**:
   「Flashに保存」ボタンを押してください。ボタンが非アクティブになり、約1〜2秒あとにマイコンからUSBの切断音が鳴り、接続状態が「未接続」に戻ります。これはマイコンが仕様通り自身をリブートさせた証拠です。
   USBケーブルを抜き差ししても変更内容が維持されていれば、完全な成功です。

> [!TIP]
> **今後の独自拡張について**
> - キーマップのデフォルト配列を変えたい場合は、`firmware/keymap.c` および `web/hid_app.js` の初期配列マトリックスの定義を調整してください。
> - 配線ピンを変更したい時は `firmware/matrix.c` の `row_pins` と `col_pins` をいじるだけで自由に変えられます。
