Keyboard Shortcuts & Tips

                
            

            

                
Editor Keyboard Shortcuts:

                
    
                    
  • ↑ ↓ ← → : Move selected keys
    • 
                    
  • Shift + ↑ ↓ ← → : Resize selected keys
    • 
                    
  • Ins / I : Add a new key
    • 
                    
  • Del : Delete selected keys
    • 
                    
  • Esc : Deselect all
    • 
                    
  • J / K : Select prev / next key
